No avatars logged yet

Avatar IDs that appear in VRChat's log (avatar changes, cache loads, lookups) show up here. Save one to add it to your favourites and clone it later. VRChat's own built-in avatars — Robot, Unity-chan and the rest of the Public and Legacy rows — are ignored, as they cannot be cloned.

Your own avatar changes arrive over OSC, and other players' avatars are read from VRChat's log the next time VRChat switches world — so this list fills as you play. Seeing other players' avatars as they load needs the local cache database, which VRChat does not create: it appears only once an avatar tracker such as VRC-LOG has written to it. The line above this list says which sources are currently producing IDs.
